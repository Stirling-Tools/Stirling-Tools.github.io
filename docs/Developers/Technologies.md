# Open-source components

Stirling PDF is built on these open-source projects. The full source is on [GitHub](https://github.com/Stirling-Tools/Stirling-PDF).

## Server

- **[PDFBox](https://pdfbox.apache.org/)** - core PDF reading and editing
- **JPDFium** - PDFium-based engine for merge, split and reading text and tables
- **[Tabula](https://github.com/tabulapdf/tabula-java)** - table extraction
- **[LibreOffice](https://www.libreoffice.org/)** - office document conversion
- **[qpdf](https://qpdf.sourceforge.io/)** and **[Ghostscript](https://www.ghostscript.com/)** - PDF optimisation and compression
- **[OCRmyPDF](https://ocrmypdf.readthedocs.io/)** with **[Tesseract](https://github.com/tesseract-ocr/tesseract)** - text recognition
- **[Calibre](https://calibre-ebook.com/)** - e-book conversion
- **[ImageMagick](https://imagemagick.org/)** and **[OpenCV](https://opencv.org/)** - image processing
- **[WeasyPrint](https://weasyprint.org/)** - HTML to PDF

## AI engine

- **[FastAPI](https://fastapi.tiangolo.com/)** and **[Pydantic AI](https://ai.pydantic.dev/)** (Python)

## Web app

- **[React](https://react.dev/)** and **[TypeScript](https://www.typescriptlang.org/)**, built with **[Vite](https://vitejs.dev/)**
- **[EmbedPDF](https://www.embedpdf.com/)** and **[PDF.js](https://mozilla.github.io/pdf.js/)** - viewing and annotation
- **[pdf-lib](https://github.com/cantoo-scribe/pdf-lib)** (Cantoo fork) - PDF editing in the browser
- **[Mantine](https://mantine.dev/)** - UI components
- **[i18next](https://www.i18next.com/)** - translations for 40+ languages

## Desktop app

- **[Tauri](https://tauri.app/)** - native app for Windows, macOS and Linux
