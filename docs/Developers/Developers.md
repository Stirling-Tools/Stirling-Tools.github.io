# Developers

Use Stirling PDF from your own code or AI assistant, on Stirling Cloud (`https://api.stirling.com`) or a self-hosted server. Both expose the same REST API, authenticated with an `X-API-KEY` header.

<Cards cols="2">
<Card title="REST API" icon="code" href="./API.md">
Base URLs, API keys, curl examples and usage limits.
</Card>
<Card title="Pipeline API" icon="bolt" href="./Pipeline-API.md">
Chain several tools on many files in one request.
</Card>
<Card title="Contributing" icon="terminal" href="./Contributing.md">
Run Stirling PDF locally and open a pull request.
</Card>
</Cards>

To let an AI assistant run the tools instead, see [MCP](../MCP/MCP.md).

The software Stirling PDF is built on is listed in [Open-source components](./Technologies.md).
