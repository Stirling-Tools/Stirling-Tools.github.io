# The Server plan has been replaced by Team

**The legacy Server plan is no longer available for new purchases.** Team is our current plan for self-hosted teams.

If you arrived here after selecting Server in Stirling PDF, your installation is showing an older purchase screen. That purchase request has not started a new payment. Update your installation to view and purchase Team.

## Update your installation

If someone else manages your Stirling PDF server, send them this page and ask them to update it. Refreshing your browser alone does not update the server.

If you manage the installation:

1. Back up your configuration and database, and review the release notes for the version you are installing.
2. Update using the instructions for your deployment:
   - [Docker and Docker Compose](./Installation/Docker%20Install.md#updating-stirling-pdf)
   - [Kubernetes](./Installation/Kubernetes.md)
   - [Windows](./Installation/Windows.md), [macOS](./Installation/Mac.md), or [Unix](./Installation/Unix.md)
   - For installations still on version 1, read the [migration guide](./Migration/Overview.md) before updating.
3. Reopen Stirling PDF and follow the [Team purchase instructions](./Paid-Offerings.md#in-app-purchase-recommended).

Review [current plans and pricing](https://www.stirling.com/pricing) before purchasing. If Server is still the only paid plan you see after updating, contact [support@stirlingpdf.com](mailto:support@stirlingpdf.com).

## Already paying for Server?

Closing Server to new purchases does not cancel an existing subscription or automatically switch it to Team. Existing subscriptions continue on their current renewal schedule unless cancelled.

You do not need to buy a second subscription because you reached this page. If you want to move an existing subscription to Team, contact [support@stirlingpdf.com](mailto:support@stirlingpdf.com) before purchasing so we can help you avoid duplicate billing.

If you have already paid but cannot find or activate your license, contact support with the email address used for the purchase.

## Unable to update yet?

Contact [support@stirlingpdf.com](mailto:support@stirlingpdf.com) with your installed version and deployment method. We can help you identify the next step. For Enterprise requirements, [contact our team](https://www.stirling.com/contact-us).
