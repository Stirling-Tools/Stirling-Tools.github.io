# Desktop app

The desktop app runs the Stirling PDF editor and most tools on your own computer, with no account needed. For tools that can't run locally, sign in to Stirling Cloud or connect to your organisation's server ([Connection modes](./Connection-Modes.md)).

| System | Download |
|---|---|
| Windows 10 or 11 (x64) | [MSI installer](https://files.stirlingpdf.com/win-installer.exe) |
| Windows on ARM | [Setup .exe](https://github.com/Stirling-Tools/Stirling-PDF/releases/latest/download/Stirling-PDF-windows-arm64-setup.exe) |
| macOS 10.15 or later (Apple silicon and Intel) | [DMG](https://files.stirlingpdf.com/mac-installer.dmg) |
| Linux (x86_64) | [DEB](https://files.stirlingpdf.com/linux-installer.deb) · [RPM](https://files.stirlingpdf.com/linux-installer.rpm) · [AppImage](https://files.stirlingpdf.com/linux-installer.AppImage) |

For winget, Homebrew and AUR, see [Install the desktop app](./Install.md).
