# All tools

Not every tool is available everywhere. In the desktop app, tools with a cloud badge need Stirling Cloud or a server ([Where your tools run](../Desktop/Where-Tools-Run.md)). On a self-hosted server, an admin can turn tools off ([Turn features on or off](../Server/Customisation/Features-and-Endpoints.md)).

## Quick access

The most-used tools sit at the top of the picker. Each one has a keyboard shortcut ([Keyboard shortcuts](./Workspace/Keyboard-Shortcuts.md)).

- **[PDF Text Editor](./Guides/Content-Editing.md#pdf-text-editor)** - edit the existing text and images in a PDF.
- **[Page Editor](./Workspace/Page-Editor.md)** (**PDF Multi Tool** in the picker) - rotate, reorder, delete, split and insert blank pages.
- **[Merge](./Guides/Page-Operations.md#merge)** - combine several PDFs into one.
- **[Compare](./Guides/Compare.md)** - show the text differences between two PDFs.
- **[Compress](./Guides/Compress.md)** - make a PDF smaller.
- **[Convert](./Guides/Convert.md)** - convert between PDF and other formats.
- **[OCR / Cleanup scans](./Guides/OCR.md)** - make scanned PDFs searchable and clean them up.
- **[Redact](./Guides/Redact.md)** - permanently black out text, areas or whole pages.

## Signing

- **[Sign with Certificate](./Security/Certificate-Signing.md#sign-with-a-certificate)** - add a digital signature that proves who signed and shows later changes.
- **[Timestamp PDF](./Security/Certificate-Signing.md#timestamping-pdfs)** - add an RFC 3161 timestamp that proves when the PDF existed.
- **[Sign](./Security/Sign.md)** - add a drawn, typed or image signature.

## Document security

- **[Add Password](./Security/Security.md#document-security)** - require a password to open the PDF and restrict what people can do.
- **[Add Watermark](./Security/Security.md#document-security)** - put a text or image watermark across the pages.
- **[Add Stamp to PDF](./Guides/Content-Editing.md#stamps-annotations)** - add a text or image stamp at a set position.
- **[Sanitize](./Security/Security.md#document-security)** - remove JavaScript, embedded files and other risky content.
- **[Flatten](./Security/Security.md#document-security)** - turn form fields and other interactive parts into plain page content.
- **[Unlock PDF Forms](./Security/Security.md#document-security)** - make read-only form fields editable again.
- **[Change Permissions](./Security/Security.md#document-security)** - allow or block printing, copying, editing and other actions.

## Verification

- **[Get ALL Info on PDF](./Security/Security.md#verification)** - show the version, fonts, page sizes, permissions and metadata.
- **[Validate PDF Signature](./Security/Certificate-Signing.md#validating-signatures)** - check who signed a PDF and whether it changed afterwards.

## Document review

- **[Read](./Workspace/Read-and-Annotate.md)** - open a PDF in the viewer to read, search, comment and mark it up.
- **[Change Metadata](./Guides/Content-Editing.md#document-details)** - edit the title, author, keywords, dates and other details.
- **[Edit Table of Contents](./Guides/Content-Editing.md#document-details)** - add, nest and reorder bookmarks.

## Page formatting

- **[Crop PDF](./Guides/Page-Operations.md#page-size-and-layout)** - trim pages to the area you want.
- **[Rotate](./Guides/Page-Operations.md#reorder-and-rotate)** - turn pages.
- **[Auto Rotate](./Guides/Page-Operations.md#reorder-and-rotate)** - detect each page's orientation and turn it upright.
- **[Split](./Guides/Page-Operations.md#split)** - split one PDF into several files.
- **[Reorganize Pages](./Guides/Page-Operations.md#reorder-and-rotate)** - rearrange, duplicate or delete pages.
- **[Adjust page size/scale](./Guides/Page-Operations.md#page-size-and-layout)** - change the page size and how big the content sits on it.
- **[Add Page Numbers](./Guides/Page-Operations.md#add-to-pages)** - number pages in a set position and format.
- **[Multi-Page Layout](./Guides/Page-Operations.md#page-size-and-layout)** - put several pages on each sheet.
- **[Booklet Imposition](./Guides/Page-Operations.md#page-size-and-layout)** - order pages for printing and folding into a booklet.
- **[PDF to Single Large Page](./Guides/Page-Operations.md#page-size-and-layout)** - join all pages into one long page.
- **[Manage Attachments](./Guides/Page-Operations.md#add-to-pages)** - add, extract, rename or delete files embedded in the PDF.
- **[Create Portfolio](./Guides/Page-Operations.md#merge)** - bundle several files into one PDF portfolio.

## Extraction

- **[Extract Pages](./Guides/Page-Operations.md#remove-and-extract-pages)** - save chosen pages as a new PDF.
- **[Extract Images](./Guides/Content-Editing.md#images)** - save every image in the PDF to a ZIP file.

## Removal

- **[Remove Pages](./Guides/Page-Operations.md#remove-and-extract-pages)** - delete the pages you choose.
- **[Remove Blank pages](./Guides/Page-Operations.md#remove-and-extract-pages)** - find and drop pages with little or no content.
- **[Remove Annotations](./Guides/Content-Editing.md#remove-content)** - delete all comments, highlights and markup.
- **[Remove image](./Guides/Content-Editing.md#remove-content)** - strip every image, for example to shrink the file.
- **[Remove Password](./Security/Security.md#removal)** - unlock a protected PDF when you know its password.
- **[Remove Certificate Sign](./Security/Security.md#removal)** - strip digital signatures so you can edit the file.

## Automation

- **[Auto Form Detection](./Guides/Fill-Form.md#detect-fields-automatically)** - find form fields and make a PDF fillable.
- **[Automate](./Guides/Automate.md)** - save a chain of tools and run it on any files.
- **[Auto Rename PDF File](./Guides/Advanced-Tools.md#auto-rename-pdf-file)** - rename a file from the title found in it.

## General

- **[Add Text](./Guides/Content-Editing.md#stamps-annotations)** - type text anywhere on a page.
- **[Add image](./Guides/Content-Editing.md#images)** - place an image anywhere on a page.
- **[Annotate](./Workspace/Read-and-Annotate.md)** - highlight, draw, add notes and shapes in the viewer.
- **[Form Editor](./Guides/Fill-Form.md)** - fill in, add and edit form fields.

## Advanced formatting

- **[Adjust Colors/Contrast](./Guides/Advanced-Tools.md#advanced-formatting)** - change contrast, brightness and saturation.
- **[Repair](./Guides/Advanced-Tools.md#repair)** - try to fix a damaged PDF.
- **[Detect & Split Scanned Photos](./Guides/Advanced-Tools.md#detect-split-scanned-photos)** - find the photos on a scanned page and save each photo as a separate image.
- **[Overlay PDFs](./Guides/Advanced-Tools.md#overlay-pdfs)** - lay one PDF over another.
- **[Replace & Invert Color](./Guides/Advanced-Tools.md#advanced-formatting)** - swap or invert colours, for example for high contrast.

## Developer tools

- **[Show Javascript](./Guides/Advanced-Tools.md#developer-tools)** - list any JavaScript inside a PDF.
- **API**, **Automated Folder Scanning**, **SSO Guide** and **Air-gapped Setup** link to the matching docs.

## AI

The AI assistant isn't in the tool list. Open it with the **Open Stirling AI assistant** button in the workspace ([AI assistant](./Guides/AI-Assistant.md)).
