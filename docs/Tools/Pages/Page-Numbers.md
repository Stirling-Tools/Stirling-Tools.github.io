# Add Page Numbers

**Add Page Numbers** stamps a number on every page, or only the pages you choose.

1. Open **Add Page Numbers** and add your file.
2. Click a square on the preview to choose where the number goes. The default is bottom centre.
3. Set which pages and numbers to use:
   - **Pages to Number** - leave blank for all pages, or enter pages such as `2-6` to skip a cover.
   - **Starting Number** - the first number shown, for example `2` so the numbers match the real page.
4. Under **Customise Appearance**, set the **Margin Size**, **Font Size** and **Font Name**. **Zero-pad Width (Bates Stamping)** adds leading zeros, so a width of 3 shows 2 as `002`.
5. Under **Custom Text Format**, wrap the number in your own words, using `{n}` for the number and `{total}` for the page count, for example `Page {n} of {total}`.
6. Click **Add Page Numbers**.
