# Manage Attachments

**Manage Attachments** lists, adds, renames, extracts and removes the files embedded in a PDF.

<Video id="dl2odVlOP44" title="Add and manage attachments" />

1. Open the tool and add a PDF. Any files already embedded in it are listed.
2. Change the attachments:
   - **Download attachment** saves one file, and **Extract all** saves every attachment at once.
   - **Add attachments** picks files from your computer. Any file type works.
   - The pencil renames an attachment, and the bin marks it for removal. **Undo delete** brings it back.
   - **Convert to PDF/A-3b** saves an archival PDF that still allows attachments.
3. Click **Save Changes**. Nothing changes until you do, and **Discard** throws the edits away.

To check the result, open the attachments panel in the viewer.
