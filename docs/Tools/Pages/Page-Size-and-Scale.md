# Adjust page size/scale

**Adjust page size/scale** puts every page on one paper size and resizes the content to fit.

<Video id="oNqRpi7GCpo" title="Change page size and scale" />

1. Open **Adjust page size/scale** and add your file.
2. Choose a **Target Page Size**: A0-A6, Letter, Legal, **Custom** width and height, or **Keep Original Size** (every page gets the size of the first page).
3. Under **Page orientation**, choose **Portrait** or **Landscape**. It is unavailable with **Custom** or **Keep Original Size**.
4. Set the **Scale Factor**. `1` fits the content to the page, lower adds a margin, higher enlarges it and can cut off the edges.
5. Click **Adjust Page Scale**.
