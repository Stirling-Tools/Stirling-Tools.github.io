# Page tools

To edit pages visually as thumbnails, use the [Page Editor](../Workspace/Page-Editor.md).

## Combine and split

- **[Merge](./Merge.md)** - join several PDFs into one.
- **[Split](./Split.md)** - break one PDF into several files.
- **[Create Portfolio](./Portfolio.md)** - bundle files of any type into one PDF, kept whole.

## Order and orientation

- **[Reorganize Pages](./Reorganize-Pages.md)** - put pages in a new order.
- **[Rotate and Auto Rotate](./Rotate.md)** - turn every page of a file, or let Auto Rotate turn sideways pages upright.

## Remove and extract

- **[Remove Pages](./Remove-Pages.md)** - delete the pages you list.
- **[Remove Blank pages](./Remove-Blank-Pages.md)** - find and drop empty pages.
- **[Extract Pages](./Extract-Pages.md)** - copy chosen pages into a new PDF.

## Size and layout

- **[Crop PDF](./Crop.md)** - trim pages to the area you want.
- **[Adjust page size/scale](./Page-Size-and-Scale.md)** - put every page on one paper size.
- **[Multi-Page Layout](./Multi-Page-Layout.md)** - fit several pages on each sheet.
- **[Booklet Imposition](./Booklet.md)** - order pages for printing as a folded booklet.
- **[PDF to Single Large Page](./Single-Large-Page.md)** - join every page into one long page.

## Add to pages

- **[Add Page Numbers](./Page-Numbers.md)** - number pages in a set position and format.
- **[Manage Attachments](./Attachments.md)** - add, extract, rename or remove embedded files.
