# Create Portfolio

**Create Portfolio** bundles several files, of any type, into a single PDF. Each file is kept whole inside it, nothing is converted.

<Video id="OVEN7szD-hI" title="Create a PDF portfolio" />

1. Open **Create Portfolio** and add at least two files. They can be PDFs, spreadsheets, images or anything else.
2. Under **Cover page title**, set the heading for the portfolio's cover page.
3. Click **Create Portfolio**. The viewer opens the cover page, with a **Portfolio** panel listing every file inside.

Click a file in the panel to preview it, or import it to open it in Stirling PDF as a separate file. PDF readers that support portfolios list the files; others show the cover page with the files attached.
