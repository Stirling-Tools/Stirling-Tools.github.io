# Merge

**Merge** joins two or more PDFs into one.

<Video id="CLq5hVFxSnQ" title="Merge PDFs: every option" />

1. Open **Merge** and add your files. Click a file in the **PDF Library** to leave it out of the merge, or put it back.
2. Set the order. Drag files by hand, or use **Sort By** (**File Name** or **Date Modified**, ascending or descending).
3. Choose any options:
   - **Generate table of contents in the merged file?** adds a bookmark at the start of each original file.
   - **Remove digital signature in the merged file?** strips signatures, which merging breaks anyway.
4. Click **Merge**. The merged PDF opens in the viewer.

To keep files separate inside one PDF, use [Create Portfolio](./Portfolio.md) instead.
