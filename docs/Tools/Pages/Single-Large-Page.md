# PDF to Single Large Page

**PDF to Single Large Page** joins every page of a file into one long page, handy for reading on screen without page breaks.

1. Open **PDF to Single Large Page** and add your file.
2. Click **Convert To Single Page**. There are no settings.

The new page is as wide as the widest page, and as tall as all of them together.
