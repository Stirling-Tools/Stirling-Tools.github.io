# Advanced tools

## Automation

### Automate

See [Automate](./Automate.md).

### Auto Rename PDF File

Renames a PDF from the title found near the start of the document. Run [OCR](./OCR.md) on scans first.

## Advanced Formatting

### Adjust Colors/Contrast

Adjust contrast, brightness and saturation, and the red, green and blue levels, with a live preview.

### Replace & Invert Color

Under **Color operation**, choose:

- **High contrast** - a preset such as white text on black or yellow text on black.
- **Custom** - pick your own text and background colours.
- **Invert all colors** - a negative of the page, for example for a dark-mode copy.
- **Convert to CMYK** - converts colours for professional printing.

### Detect & Split Scanned Photos

Finds each photo on a scanned page and saves it as a separate image. Scan on a plain, light background with a small gap between photos.

### Overlay PDFs

Lays the pages of one or more overlay PDFs over a base PDF.

1. Under **Select Overlay PDF Files**, add the overlay PDFs.
2. Under **Select Overlay Mode**, choose:
   - **Sequential Overlay** uses pages from the first overlay until it ends, then the next.
   - **Interleaved Overlay** takes one page from each overlay in turn.
   - **Fixed Repeat Overlay** takes a set number of pages from each overlay. Enter the numbers under **Overlay Counts (for Fixed Repeat Mode)**.
3. Under **Select Overlay Position**, choose **Foreground** or **Background**.

### Repair

Tries to fix a corrupt or damaged PDF, for example one that won't open.

## Developer Tools

- **Show Javascript** - lists any JavaScript embedded in a PDF.
