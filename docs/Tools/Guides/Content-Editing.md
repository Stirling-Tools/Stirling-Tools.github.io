# Content and editing

## PDF Text Editor

**PDF Text Editor** lets you edit the existing text and images of a PDF. Click **Save PDF** to apply your changes to the file in your workspace, or **Download** to save a copy.

:::warning[Alpha]
Fonts and layout can shift slightly, so check the result and keep your original.
:::

## Images

- **Add image** - upload a PNG, JPEG, GIF, BMP, TIFF or SVG file, then click anywhere on the page to place it. Click **Apply Images** when you're done.
- **Extract Images** - saves every image in the PDF to a ZIP file. Choose the image format to convert them to, and tick **Save duplicate images** to keep repeats.

To split a scan of several photos into separate images, use [Detect & Split Scanned Photos](./Advanced-Tools.md#detect-split-scanned-photos).

## Stamps & annotations

- **Add Text** - type your text, click on the page to place it, then click **Apply Text**.
- **Add Stamp to PDF** - add a text or image stamp. Set its position (or drag it in the preview), size, rotation, opacity and margin. Stamp text can include dynamic variables such as the current date, the file name or the page number.
- **Annotate** - highlight, draw, and add notes and shapes in the viewer. See [Read and annotate](../Workspace/Read-and-Annotate.md).

## Remove content

- **Remove image** - strips every image from the PDF.
- **Remove Annotations** - deletes all comments, highlights and markup.

## Document details

- **Change Metadata** - edit the standard fields (author, title, subject, keywords, creator, producer, creation and modification dates), add your own fields under **Custom Metadata**, or tick **Delete all metadata** to strip them.
- **Edit Table of Contents** - add, nest and reorder bookmarks in the **Bookmark editor**. Click **Load from selected PDF** to start from the existing bookmarks, and use **Import JSON** or **Download JSON** to reuse an outline. Click **Apply table of contents** to save.
