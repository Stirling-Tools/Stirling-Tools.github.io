# Read and annotate

Open a PDF in the viewer to read it, search it and mark it up. Two tools open the viewer:

- **Read** (under **Document Review** in the tool picker) opens the file for reading and commenting. You can also click **Reader** in the left rail.
- **Annotate** (under **General**) opens the viewer with the annotation tools in the side panel.

## Viewer

- Switch between **Single Page View** and **Dual Page View**.
- Open the **Bookmarks**, **Attachments** and **Comments** sidebars.
- Search the text, select it and click **Copy**.
- Print with **Print PDF**.

For shortcuts, see [Keyboard shortcuts](./Keyboard-Shortcuts.md#pdf-viewer-shortcuts).

## Annotation tools

| Group | Tools |
|---|---|
| **Text Markup** | Highlight, Underline, Strikeout, Squiggly |
| **Drawing** | Pen, Freehand Highlighter |
| **Shapes** | Square, Circle, Line, Polygon |
| **Comments** | Comment, Insert Text, Replace Text |
| **Notes & Stamps** | Text box, Note, Add Image |

Use **Select and Edit** to move, resize or change an annotation you've placed.

To sign a PDF, use [Sign](../Security/Sign.md) instead.

## Comments

The **Comments** sidebar lists comments by page, in reading order. From there you can:

- reply to a comment
- click **Locate in document** to jump to it
- search comments
- remove every comment with **Clear all comments** (annotations stay in the document)

## Save your changes

Click **Save Changes** or press **Ctrl + S**. Annotations are saved as standard PDF annotations that other readers can show.
