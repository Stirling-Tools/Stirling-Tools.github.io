# Keyboard shortcuts

On a Mac, use **⌘** for **Ctrl** and **⌥** for **Alt**.

## Tool shortcuts

The tools in the picker's Quick access list get **Ctrl + Alt + 1** to **8** by default, in list order:

| Shortcut | Tool |
|---|---|
| `Ctrl + Alt + 1` | PDF Text Editor |
| `Ctrl + Alt + 2` | PDF Multi Tool |
| `Ctrl + Alt + 3` | Merge |
| `Ctrl + Alt + 4` | Compare |
| `Ctrl + Alt + 5` | Compress |
| `Ctrl + Alt + 6` | Convert |
| `Ctrl + Alt + 7` | OCR / Cleanup scans |
| `Ctrl + Alt + 8` | Redact |

Other tools have no shortcut until you add one. Shortcuts are saved in this browser (or in the desktop app on this computer), so they don't follow you to other devices.

### Change a shortcut

1. Open **Settings → Preferences** and expand **Keyboard Shortcuts**.
2. Find the tool and click **Change shortcut**.
3. Press the new key combination, or press **Esc** to cancel.

A shortcut must include **Ctrl**, **Alt** or **⌘**. **Shift** on its own doesn't count. If another tool already uses the combination, you'll see **Shortcut already used by** and the tool's name.

To go back to the default, click **Reset**. For a tool with no default, **Reset** removes the shortcut.

## PDF viewer shortcuts

Print, select all and zoom work whenever the viewer is open. The rest work while your pointer is over the viewer.

| Shortcut | Action |
|---|---|
| `Ctrl + P` | Print |
| `Ctrl + A` | Select all text |
| `Ctrl + =` or `Ctrl + +` | Zoom in |
| `Ctrl + -` | Zoom out |
| `Ctrl + 0` | Fit to width |
| `Ctrl + F` | Open or focus search |
| `Ctrl + S` | Save changes |
| `Ctrl + Z` | Undo |
| `Ctrl + Shift + Z` or `Ctrl + Y` | Redo |
| `Home` / `End` | First / last page |
| `Page Up` / `Page Down` | Previous / next page |
| `Esc` | Close search |

With the **Rotate** tool open, press `←` to rotate left and `→` to rotate right.

## Desktop app shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl + S` | Save the selected files to disk, or all files if none are selected. Files that didn't come from disk open a **Save As** dialog. |
| `Ctrl + N` | Open a new empty window (Windows and macOS only). |
| `Ctrl + R` / `Ctrl + Shift + R` | Rotate the view in the viewer clockwise / anticlockwise. |
