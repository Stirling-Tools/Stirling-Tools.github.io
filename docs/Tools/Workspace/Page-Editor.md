# Page Editor

The **Page Editor** shows every page of every open file as a thumbnail, so you can move, rotate, delete, split and insert pages visually.

<Video id="FpGYOcY4q34" title="Rearrange, rotate and delete PDF pages" />

1. Open **Page Editor** from the top bar, or pick **PDF Multi Tool** in the tool picker. Each file gets its own row of page thumbnails.
2. Select pages with their checkboxes, with **Select All**, or with **Select by Page Numbers**.
3. Change the pages:
   - Drag pages to reorder them, or drop them into another file's row.
   - Hover over a page for **Move left**, **Move right**, **Rotate left**, **Rotate right**, **Duplicate page**, **Delete page** and **View page**.
   - Hover between two pages for **Split here** or **Insert blank page**.
   - For several pages at once, use **Rotate selected pages left**, **Rotate selected pages right**, **Delete selected pages**, **Insert blank pages after selected pages**, **Split after selected pages**, **Duplicate selected pages** or **Download selected pages**.
   - Click a file's name to rename it. Images get their own row; drag them into a PDF's row to add them as pages.
4. Use **Wrap pages**, **Zoom in** and **Zoom out** to change the view, and **Undo** and **Redo** if you change your mind.
5. Click **Save changes to all files** to apply your edits.

To run the same steps on many files, use [Automate](../Advanced/Automate.md).
