# Workspace and Page Editor

Add your files to the workspace once, then run as many tools on them as you like. The **Page Editor** lets you edit their pages as thumbnails.

## The workspace

- Drag files onto the app or click **Add files**. They appear in the file sidebar under **PDF Library**.
- Workspace files are kept in this browser (in the desktop app, on this computer). To keep a file on the server or share it, see [My files and sharing](./Files-and-Sharing.md).
- After a tool runs, click **Undo** to restore the files as they were.
- Each tool run saves a new version of the file. To see earlier versions, open the file's **More actions** menu in the sidebar and choose **Version history**. From there you can open an earlier version in the workspace or remove it.

## Edit pages in the Page Editor

1. Open **Page Editor** from the top bar, or pick **PDF Multi Tool** in the tool picker. Each file gets its own row of page thumbnails.
2. Select pages with their checkboxes, with **Select All**, or with **Select by Page Numbers**.
3. Change the pages:
   - Drag pages to reorder them, or drop them into another file's row.
   - Hover over a page for **Move left**, **Move right**, **Rotate left**, **Rotate right**, **Delete page** and **View page**.
   - Hover between two pages for **Split here** or **Insert blank page**.
   - For several pages at once, use **Rotate selected pages left**, **Rotate selected pages right**, **Delete selected pages**, **Insert blank pages after selected pages** or **Split after selected pages**.
4. Use **Wrap pages**, **Zoom in** and **Zoom out** to change the view, and **Undo** and **Redo** if you change your mind.
5. Click **Save changes to all files** to apply your edits.

To run the same steps on many files, use [Automate](../Guides/Automate.md).
