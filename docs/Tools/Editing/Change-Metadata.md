# Change Metadata

**Change Metadata** edits the details stored inside a PDF, like its title, author and dates. Its current details fill in the fields when you add the file.

1. Open **Change Metadata** and add your PDF.
2. Edit any field:
   - **Standard Fields** - title, author, subject and keywords, plus the **Creator** and **Producer** apps.
   - **Date Fields** - when the file was created and last changed.
   - **Trapped Status** (under advanced options) - whether the file is prepared for commercial printing.
   - **Custom Metadata** - add your own entries, for example a department or project code.
3. To strip everything instead, tick **Delete all metadata**. This includes the hidden XMP copy.
4. Click **Change** to save a new version of the file.
