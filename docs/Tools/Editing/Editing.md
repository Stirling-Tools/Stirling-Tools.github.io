# Content and editing tools

## Edit and add content

- **[PDF Text Editor](./PDF-Text-Editor.md)** - edit the existing text, tables and images in a PDF.
- **[Add image](./Add-Image.md)** - place a logo, stamp or photo anywhere on a page.
- **[Add Text](./Add-Text.md)** - type new text anywhere on a page.
- **[Add Stamp to PDF](./Add-Stamp.md)** - add a text, image or QR code stamp at a set position.
- **[Annotate](../Workspace/Read-and-Annotate.md)** - highlight, draw, and add notes and shapes in the viewer.

## Extract and remove

- **[Extract Images](./Extract-Images.md)** - save every picture in a PDF as its own file.
- **[Remove image](./Remove-Images.md)** - strip every image from a PDF.
- **[Remove Annotations](./Remove-Annotations.md)** - delete all comments, highlights and markup.

## Document details

- **[Change Metadata](./Change-Metadata.md)** - edit the title, author, dates and other details.
- **[Edit Table of Contents](./Table-of-Contents.md)** - add, nest and reorder bookmarks.
