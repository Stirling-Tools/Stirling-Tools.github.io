# Remove Annotations

**Remove Annotations** clears comments, highlights and markup from a PDF in one click.

<Video id="-8IS5yLiee0" title="Remove annotations" />

1. Open **Remove Annotations** and add your PDF.
2. Click **Remove**. There are no settings.

Every annotation on every page is removed, including links. The text and layout stay.
