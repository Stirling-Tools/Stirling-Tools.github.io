# Add Text

**Add Text** stamps new text anywhere on a PDF, such as a name, a date or a note.

<Video id="fMZ6kDW_dZI" title="Add text to a PDF" />

1. Open **Add Text** and add your PDF. It opens in the viewer.
2. Type what you want to add under **Text content**.
3. Pick a **Font**, a **Font size** from 8 to 200, and a **Text colour**. Type a hex code for an exact colour.
4. Click the page where the text should go. Placement stays on, so each click adds the text again.
5. Click **Pause placement** to stop adding. Drag text to move it, or use the bin to delete it.
6. Click **Apply Text** to save it into the PDF.

The text is stamped on top of the page as an image, so it can't be edited as text or searched. To change words already in the PDF, use [PDF Text Editor](./PDF-Text-Editor.md).
