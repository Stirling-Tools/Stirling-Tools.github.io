# Edit Table of Contents

**Edit Table of Contents** builds the bookmarks a PDF shows in its outline, so readers can jump to each section.

<Video id="Gkf2LWP_9EU" title="Edit the table of contents" />

1. Open **Edit Table of Contents** and add your PDF. If the file already has bookmarks, they load into the **Bookmark editor**.
2. Each bookmark has a title and the page it opens. Edit either one.
3. The plus button adds a bookmark straight after this one. The arrow button adds a child inside it, for sections within a chapter. **Add top-level bookmark** adds one at the end.
4. To reuse an outline, save it as JSON or import a JSON file.
5. Click **Apply table of contents**. The list becomes the file's whole outline.

To check, open **Bookmarks** in the viewer.
