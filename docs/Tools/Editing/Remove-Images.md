# Remove image

**Remove image** deletes the pictures from a PDF and keeps all of the text, for example to make a lighter, text-only copy.

<Video id="duLM1nayu4E" title="Remove images" />

1. Open **Remove image** and add your PDF.
2. Click **Remove image**. There are no settings.

Every embedded image on every page is removed. Text, tables and coloured shapes stay where they were.
