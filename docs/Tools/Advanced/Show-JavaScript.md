# Show Javascript

**Show Javascript** reveals the scripts inside a PDF, so you can check them before you trust the file. Scripts in a PDF can run as soon as it opens.

1. Open **Show Javascript** and add one PDF.
2. Click **Show**. Every document-level script is listed with its name.
3. Search the code, copy it, or download it as a JavaScript file.

To remove the scripts, use [Sanitize](../Security/Sanitize.md) with **Remove JavaScript** ticked.
