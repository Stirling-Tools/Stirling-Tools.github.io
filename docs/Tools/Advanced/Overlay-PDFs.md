# Overlay PDFs

**Overlay PDFs** lays the pages of one or more overlay PDFs over or under a base PDF, for example a letterhead behind every letter.

1. Open **Overlay PDFs** and add the PDF you want to change.
2. Under **Select Overlay PDF Files**, add the overlay PDFs.
3. Under **Select Overlay Mode**, choose:
   - **Sequential Overlay** uses pages from the first overlay until it ends, then the next.
   - **Interleaved Overlay** takes one page from each overlay in turn.
   - **Fixed Repeat Overlay** takes a set number of pages from each overlay. Enter the numbers under **Overlay Counts (for Fixed Repeat Mode)**, for example a full letterhead on page one and a smaller header after it.
4. Under **Select Overlay Position**, choose **Foreground** (on top, like a stamp) or **Background** (behind, like letterhead paper).
5. Click **Submit**.

To repeat text or a logo across every page, use [Add Watermark](../Security/Watermark.md).
