# Remove Password

**Remove Password** unlocks a protected PDF, as long as you know its password.

1. Open **Remove Password** and add your PDF. If it needs a password to open, Stirling PDF asks for it straight away. Choose **Skip for now** to use the tool instead.
2. Type the **Current Password**. The open password and the owner password both work.
3. Click **Remove Password**.

Permission restrictions are kept. To change them, use [Change Permissions](./Change-Permissions.md).
