# Check PDF accessibility

**Check PDF accessibility** checks a PDF against **PDF/UA-1** or **PDF/UA-2** without changing it.

Each file gets **Pass**, **Partial** or **Fail**. **Download accessibility report** saves the results as a PDF.

To tag a PDF for screen readers, convert it to PDF/UA with [Convert](../Guides/Convert.md).
