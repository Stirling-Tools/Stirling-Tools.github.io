# Flatten

**Flatten** fixes a PDF's content in place, so form fields and other interactive parts can't be changed.

1. Open **Flatten** and add your PDF, for example a filled-in form.
2. Choose how far to go:
   - Tick **Flatten only forms** to turn just the form fields into plain page content. Links and comments keep working.
   - Leave it unticked to turn every page into an image. **Rendering DPI** sets the sharpness; higher values look sharper but make bigger files.
3. Click **Flatten**.
