# Get ALL Info on PDF

**Get ALL Info on PDF** builds a full report on a file and leaves the PDF itself unchanged.

1. Open **Get ALL Info on PDF** and add a PDF.
2. Click **Get Info**.

The report covers the page count, file size and PDF version, the metadata, whether the file is encrypted or restricted, what it allows (printing, copying, filling in forms), and counts of images, fonts, form fields and scripts. **Per Page Info** shows each page's size, orientation, fonts, images and links. Use the index to jump to any section, and **Download JSON** to save the whole report.
