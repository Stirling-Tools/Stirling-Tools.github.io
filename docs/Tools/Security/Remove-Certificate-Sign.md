# Remove Certificate Sign

**Remove Certificate Sign** strips the digital signatures from a PDF, for example so you can edit it and sign it again.

1. Open **Remove Certificate Sign** and add the signed PDF.
2. Click **Remove Signature**. There are no settings.

Every signature and timestamp is removed. A visible signature block stays on the page as plain content. To confirm, run [Validate PDF Signature](./Certificate-Signing.md#validating-signatures).
