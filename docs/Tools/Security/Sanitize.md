# Sanitize

**Sanitize** removes hidden content from a PDF, like scripts, attached files and author details.

1. Open **Sanitize** and add your PDF. To see what a file carries first, run [Get ALL Info on PDF](./Get-PDF-Info.md).
2. Tick what to remove:
   - **Remove JavaScript** - scripts that run when the file opens or a field changes.
   - **Remove Embedded Files** - attached files.
   - **Remove XMP Metadata** and **Remove Document Metadata** - details like the title, the author and the app that made it.
   - **Remove Links** - web links and links that open other files.
   - **Remove Fonts** - usually breaks how text displays, so leave it off.
3. Click **Sanitize**.
