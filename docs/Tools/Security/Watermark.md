# Add Watermark

**Add Watermark** repeats text or an image across every page, for example a CONFIDENTIAL mark.

1. Open **Add Watermark** and add your PDF.
2. Under **Watermark Type**, choose **Text** or **Image**.
   - For text, type the wording, then pick the colour and a font that covers your script, like Arabic or Japanese.
   - For an image, choose the picture.
3. Under **Formatting**, set the size, rotation and opacity, and the horizontal and vertical spacing between copies.
4. Tick **Flatten PDF pages to images** to make the watermark hard to remove. The text can then no longer be selected.
5. Click **Add Watermark**.
